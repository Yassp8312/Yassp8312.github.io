# Portafolio · Jorge Ricardo Cintra Rad

Concepto **Diseño / Código**: una lupa sigue al cursor y revela el código que hay detrás del diseño. El botón Diseño/Código del menú lo muestra todo de golpe.

## Estructura
- `index.html`: la página
- `css/styles.css`: estilos
- `js/data.js`: **contenido** (proyectos y textos en español e inglés). Para agregar un proyecto, copia un objeto de `PROJECTS`.
- `js/main.js`: lupa, modo código, idioma y terminal

No necesita instalar nada ni compilar: abre `index.html` en el navegador.

## Secretos
- Presiona `~` o toca "¿Eres dev?" en el pie de página para abrir la terminal.
- En la terminal prueba `xray` y `abracadabra`.

## Publicar gratis
Sube estos archivos a un repo llamado `Yassp8312.github.io` y activa GitHub Pages en Settings → Pages (rama `main`, carpeta raíz).
